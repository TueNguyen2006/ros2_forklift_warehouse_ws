# Kinematics And Dynamics Lab

Purpose:

```text
Inspect rear-steer four-wheel forklift kinematics at wheel level.
```

Structure:

```text
app.py
    Matplotlib UI and animation loop.

KINEMATICS_REAR_STEER_FORKLIFT.md
    Formula reference for rear-steer 4-wheel kinematics.

scenarios/
    Future preset wheel-speed and steering cases.

assets/
    Future images or exported plots.
```

The app imports formulas from `warehouse_visual_localization.core`; do not copy
kinematics formulas into this folder.
